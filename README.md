# Time to Color

윤현수의 [개인 포트폴리오](https://mixx98.github.io/Time_to_Color/)입니다. 대표 프로젝트, 활동과 사진을 소개하고, 현지 시간이나 직접 입력한 시각을 색으로 보여줍니다.

하루 86,400,000ms에 RGB 16,777,216가지와 투명도 5단계를 조합한 83,886,080개의 색상 코드를 배정합니다. 약 1.03ms마다 한 가지 코드가 대응합니다.

색을 보거나 방명록에 시간을 남기려면 `14:30:00:000`처럼 시·분·초·밀리초를 입력하세요. 방명록은 같은 브라우저의 localStorage에 저장됩니다.

## 로컬 실행

정적 HTML, CSS, JavaScript로 구성되어 있습니다. 저장소 루트에서 `python3 -m http.server 8000`을 실행한 뒤 `http://localhost:8000`을 여세요.
